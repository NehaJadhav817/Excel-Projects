# Excel Employee Data Cleaning and Validation

## Project Overview
This project focuses on cleaning, validating, and organizing employee-related data using Microsoft Excel. It involves working with employee records, project allocations, compensation reviews, and a cleaned master dataset.

The workbook includes 20 questions covering data cleaning, missing values, duplicate records, data validation, and data consistency.

## Tools and Features Used
- Microsoft Excel
- TRIM and IF Functions
- AVERAGE
- COUNTIF
- Data Validation
- Conditional Formatting
- Flash Fill
- Duplicate Removal
- Data Standardization

## Workbook Sheets
- **Employee_Master:** Contains employee IDs, names, departments, designations, locations, email addresses, salaries, joining dates, and employment status.
- **Project_Allocation:** Contains employee project assignments, client names, project dates, and billable status.
- **Compensation_Review:** Contains employee review years, performance ratings, bonus percentages, and reviewer information.
- **Data_Cleaning_Questions:** Contains 20 questions related to employee data cleaning and validation.
- **cleaned_master_dataset:** Contains a combined employee dataset for cleaning and analysis.
- **Employee Master List:** Contains employee ID mapping information and project allocation details.

## Key Activities
- Identifying duplicate employee records.
- Removing extra spaces from text fields.
- Standardizing department names and employment status.
- Handling missing salary and joining date values.
- Splitting full names into first and last names.
- Creating missing email IDs using Flash Fill.
- Applying data validation to status and billable status fields.
- Using conditional formatting to highlight salary and performance conditions.
- Identifying employees without project allocations or compensation reviews.
- Handling missing performance ratings.
- Standardizing date formats.
- Validating employee ID mappings across multiple sheets.
- Preparing a cleaned master dataset.

## Learning Outcomes
- Improved understanding of data cleaning techniques in Excel.
- Practiced handling missing values and duplicate records.
- Learned to standardize inconsistent data.
- Gained experience with data validation and conditional formatting.
- Practiced checking consistency across multiple worksheets.
- Developed skills in preparing structured datasets for analysis.
