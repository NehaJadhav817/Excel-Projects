# Excel Text to Columns and Flash Fill

## Project Overview
This project focuses on organizing and transforming text data using Microsoft Excel. It includes exercises involving different delimiters, names, dates, addresses, email IDs, and Flash Fill.

## Tools and Features Used
- Microsoft Excel
- Text to Columns
- Flash Fill
- Text Splitting
- Basic Data Cleaning

## Workbook Sheets
- **Comma_Delimited:** Employee data separated using commas.
- **Pipe_Delimited:** Employee data using pipe delimiters.
- **Semicolon_Delimited:** Data separated using semicolons.
- **Space_Delimited:** Employee data separated using spaces.
- **Mixed_Delimiters:** Data containing different delimiters.
- **Name_Split:** Splitting names into separate fields.
- **Date_Text:** Working with date, ID, and salary data.
- **Address_Data:** Organizing address components into separate fields.
- **Email_IDs:** Working with email IDs and text extraction.
- **FlashFill_Challenge:** Separating combined text into individual fields using Flash Fill.

## Key Activities
- Separating text into columns using different delimiters.
- Organizing comma-, pipe-, semicolon-, and space-separated data.
- Splitting names into separate columns.
- Working with data containing mixed delimiters.
- Organizing date, ID, and salary information.
- Separating address components.
- Working with email IDs.
- Using Flash Fill to extract information from combined text.

## Learning Outcomes
- Learned how to use Text to Columns in Excel.
- Practiced separating text using different delimiters.
- Improved understanding of Flash Fill.
- Practiced organizing unstructured text into structured columns.
- Developed basic data preparation and text transformation skills.
