# Excel XLOOKUP Practice Project

## Project Overview
This project focuses on practicing the XLOOKUP function in Microsoft Excel using product, customer, sales, region, and discount data.

The workbook contains 20 practice questions covering data retrieval, conditional lookups, and sales calculations.

## Tools Used
- Microsoft Excel
- XLOOKUP
- IF Function
- Basic Arithmetic Formulas

## Dataset Information
The workbook contains the following tables:

- Product Master: Product IDs, product names, categories, brands, prices, and stock.
- Customer Master: Customer IDs, names, cities, states, ages, and genders.
- Sales Data: Invoice IDs, customer IDs, product IDs, quantities, and invoice dates.
- Region Master: States and their corresponding regions.
- Discount Master: Product categories and discount percentages.

## Project Activities
- Retrieved product names, brands, categories, and prices using XLOOKUP.
- Retrieved customer names, cities, and states using customer IDs.
- Identified regions based on customer states.
- Retrieved discount percentages based on product categories.
- Practiced handling invalid product IDs.
- Combined XLOOKUP with IF for conditional results.
- Practiced calculating total amounts, discount values, and net amounts.
- Worked on lookup-based sales analysis questions.

## Learning Outcomes
- Improved understanding of the XLOOKUP function.
- Practiced retrieving information from multiple data tables.
- Learned to combine lookup functions with conditional logic.
- Practiced formula-based sales calculations.
- Developed Excel data-handling and problem-solving skills.
