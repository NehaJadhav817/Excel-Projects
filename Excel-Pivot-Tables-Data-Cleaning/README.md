# Excel Pivot Tables and Data Cleaning

## Project Overview
This project focuses on data cleaning, data transformation, and data summarization using Microsoft Excel. It includes electricity consumption data and sales transaction data to practice organizing raw data and analyzing it using Pivot Tables.

## Tools and Features Used
- Microsoft Excel
- Data Cleaning
- Text and Date Formatting
- Pivot Tables
- Conditional Formatting
- Data Summarization
- Excel Formulas

## Workbook Sheets

- **Electricity Consumption:** Contains raw electricity consumption records with time, date, and consumption values.
- **Consumption data:** Contains organized electricity consumption data, including time, date, consumption, day, and month.
- **Requirment:** Lists the tasks related to cleaning and analyzing electricity consumption data.
- **requirements ans:** Contains a Pivot Table summarizing electricity consumption by month and day of the week.
- **Project 2:** Contains sales transaction data, including product descriptions, quantities, regions, amounts, and dates.
- **Project2 answer:** Contains a Pivot Table summarizing sales amounts by month and region.

## Key Activities
- Organizing raw electricity consumption data into a readable format.
- Extracting and formatting date and time information.
- Preparing data for analysis using Excel formulas.
- Summarizing electricity consumption by month and day of the week.
- Analyzing sales amounts across different regions and months.
- Using Pivot Tables to calculate totals and compare categories.
- Practicing data cleaning and data summarization techniques.

## Learning Outcomes
- Improved understanding of data cleaning in Excel.
- Practiced working with date and time data.
- Learned to summarize large datasets using Pivot Tables.
- Improved skills in analyzing monthly and regional data.
- Gained experience organizing raw data for further analysis.
