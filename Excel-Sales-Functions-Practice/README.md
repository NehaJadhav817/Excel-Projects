# Excel Sales Functions Practice Project

## Project Overview
This project contains practical Excel exercises based on sales data. It focuses on using Excel functions to calculate totals, count records, and analyze sales based on specific criteria.

## Tools Used
- Microsoft Excel

## Excel Functions Practiced
- SUMIF – Calculates totals based on a single condition.
- COUNTIF – Counts records that meet a specific condition.
- SUMIFS – Calculates totals based on multiple conditions.
- COUNTIFS – Counts records based on multiple conditions.

## Project Activities
- Worked with sales data containing regions, product categories, salespersons, units sold, unit prices, and revenue.
- Solved practice questions using Excel formulas.
- Calculated sales totals and revenue based on different criteria.
- Counted records based on regions, categories, and other conditions.
- Practiced applying single and multiple criteria in formulas.

## Learning Outcomes
- Improved understanding of Excel conditional functions.
- Practiced formula-based calculations and sales data analysis.
- Developed problem-solving skills using Excel.

## Project File
- `Excel-Sales-Functions-Practice.xlsx` – Contains sales data, practice questions, and formula-based solutions.
