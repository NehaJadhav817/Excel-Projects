# Excel Sales Performance Dashboard

## Project Overview
This project involves analyzing sales data and creating a Sales Performance Dashboard using Microsoft Excel. The dashboard provides insights into sales, profit, orders, product categories, regions, and sales representatives.

The project demonstrates the use of Excel data analysis, Pivot Tables, formulas, and data visualization to summarize sales performance and support business decision-making.

## Tools and Features Used
- Microsoft Excel
- Pivot Tables
- Excel Formulas
- SUMIFS and COUNTIFS
- Data Analysis
- Charts and Data Visualization
- Conditional Formatting
- Interactive Filters and Slicers

## Dataset Information
The workbook contains 1,500 sales records with information about orders, customers, products, sales representatives, revenue, discounts, and profit.

## Workbook Sheets
- **Sales_Data:** Contains sales transactions, order dates, regions, customer segments, product categories, sales representatives, quantities, revenue, and profit.
- **Dashboard_Blueprint:** Documents the dashboard layout, KPIs, charts, and filters.
- **Data_Dictionary:** Describes the columns used in the sales dataset.
- **Sheet2:** Contains summary tables used for sales analysis and visualization.
- **Sheet1, Sheet3, Sheet4:** Additional worksheets included in the workbook.

## Key Analysis Areas
- Sales performance by region.
- Sales distribution across product categories.
- Monthly sales trends.
- Profit performance by sales representative.
- Sales channel contribution.
- Total sales and total profit.
- Order volume and average discount.
- Profit margin analysis.

## Dashboard Features
- KPI cards for key sales performance indicators.
- Charts to compare sales across regions and product categories.
- Monthly sales trend visualization.
- Profit comparison by sales representative.
- Sales channel contribution analysis.
- Interactive filters for exploring sales data across different categories.

## Learning Outcomes
- Applied Excel data analysis techniques to sales data.
- Used Pivot Tables to summarize sales information.
- Analyzed sales and profit performance across multiple dimensions.
- Created visualizations to communicate business insights.
- Practiced KPI-based reporting and dashboard development.
