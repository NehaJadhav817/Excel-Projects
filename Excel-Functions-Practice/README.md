# Excel Functions Practice

## Project Overview
This project focuses on practicing Excel functions and formulas using student data. The workbook includes student names, locations, marks, total marks, percentages, and ranks.

## Tools Used
- Microsoft Excel

## Topics Covered
- Auto Fill
- Text Join
- SUM
- COUNT
- AVERAGE
- RANK
- SUMIF
- COUNTIF
- IF
- FILTER
- Cell Formatting

## Project Activities
- Combined first and last names using Excel formulas.
- Calculated total marks and percentages.
- Practiced ranking students based on their marks.
- Used basic mathematical and statistical functions.
- Applied conditional functions to analyze data.
- Practiced organizing and formatting spreadsheet data.

## Learning Outcomes
- Improved understanding of Excel functions and formulas.
- Practiced calculations using student marks data.
- Developed skills in text manipulation and conditional calculations.
- Gained practical experience in spreadsheet operations.

## Project File
- `Excel-Functions-Practice.xlsx` – Contains student data and Excel function practice exercises.
