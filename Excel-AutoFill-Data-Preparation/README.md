# Excel AutoFill and Data Preparation

## Project Overview
This project focuses on practicing data organization and data preparation techniques in Microsoft Excel. It includes exercises involving combined text data, extracting information into separate columns, and working with structured datasets.

## Tools and Features Used
- Microsoft Excel
- AutoFill
- Text Extraction
- Data Organization
- Basic Excel Data Preparation

## Workbook Sheets
- **Marksheet to understand Xlookup:** Contains student details and subject-wise marks.
- **Auto fill:** Contains combined employee details, including names, cities, mobile numbers, and email IDs, organized into separate columns.
- **Autofill 2:** Contains combined data and structured fields related to products, regions, agents, customers, call duration, resolution, satisfaction, and up-sell amounts.
- **Requiement:** Contains structured data related to product, region, agent, customer type, call duration, resolution, satisfaction ratio, and up-sell amount.

## Key Activities
- Working with combined text data.
- Separating names, cities, mobile numbers, and email IDs into individual columns.
- Organizing data into a structured format.
- Working with product and customer-related datasets.
- Practicing Excel data preparation techniques.
- Exploring student marksheet data and subject-wise marks.

## Learning Outcomes
- Improved understanding of Excel data organization.
- Practiced separating combined data into individual fields.
- Gained experience working with structured datasets.
- Developed basic Excel data preparation skills.
