# Excel Text and DateTime Functions Practice

## Project Overview
This project focuses on practicing text, date, and time functions in Microsoft Excel. It uses employee data, attendance records, customer feedback, and event schedules to solve practical Excel questions.

The workbook includes 30 practice questions to improve Excel formula-writing and data-handling skills.

## Tools Used
- Microsoft Excel
- Text Functions
- Date and Time Functions
- IF Function
- COUNTIF and COUNTIFS
- SUMIFS

## Dataset Information
The workbook contains the following sheets:

- **Employee_Data:** Contains employee information, email addresses, departments, and joining dates.
- **Attendance_Log:** Contains attendance dates, in-time, out-time, work hours, and late status.
- **Customer_Feedback:** Contains customer feedback data for text-based analysis.
- **Event_Schedule:** Contains event names, start dates, end dates, and related details.
- **Questions_Sheet:** Contains practice questions based on the datasets.

## Key Activities
- Extracting first names and last names from full names.
- Converting text into uppercase and proper case.
- Calculating text length and combining text values.
- Extracting email domains.
- Extracting years and months from dates.
- Calculating employee tenure and event durations.
- Analyzing attendance and late arrivals.
- Identifying weekends.
- Searching for specific words in customer feedback.
- Replacing text and removing extra spaces.
- Performing date and time calculations.

## Learning Outcomes
- Practiced Excel text functions.
- Improved understanding of date and time calculations.
- Learned to combine functions with conditional logic.
- Improved Excel formula-writing and data-handling skills.
- Developed problem-solving skills using multiple datasets.
