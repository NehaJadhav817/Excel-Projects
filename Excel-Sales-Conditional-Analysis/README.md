# Excel Sales Conditional Analysis

## Project Overview
This project focuses on solving practical sales data analysis questions using Excel conditional functions. The workbook contains sales records and questions related to sales amounts, revenue, order counts, product categories, regions, cities, customers, and payment methods.

## Tools Used
- Microsoft Excel

## Excel Functions Practiced
- SUMIF – Calculates totals based on a single condition.
- COUNTIF – Counts records that meet a single condition.
- SUMIFS – Calculates totals based on multiple conditions.
- COUNTIFS – Counts records that meet multiple conditions.

## Dataset Information
The sales dataset includes:
- Order ID and Order Date
- Region and City
- Sales Representative
- Customer Type
- Product Category and Product Name
- Quantity and Unit Price
- Sales Amount and Payment Mode

## Project Activities
- Solved 40 practice questions based on sales data.
- Calculated sales amounts and revenue for different regions, cities, products, and customer types.
- Counted orders based on payment methods and sales criteria.
- Applied multiple conditions to analyze sales performance.
- Practiced conditional calculations using Excel formulas.

## Learning Outcomes
- Improved understanding of conditional Excel functions.
- Practiced sales data analysis using formulas.
- Developed skills in applying single and multiple criteria.
- Strengthened Excel-based problem-solving skills.

- `Excel-Sales-Conditional-Analysis.xlsx` – Contains the sales dataset, practice questions, and solutions.
