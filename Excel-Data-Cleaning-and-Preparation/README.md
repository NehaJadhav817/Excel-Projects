# Excel Data Cleaning and Preparation

## Project Overview
This project focuses on data cleaning and preparation using Microsoft Excel. It involves working with employee records, sales transactions, customer information, and product data to identify and handle common data quality issues.

The workbook contains 30 questions covering data cleaning, text standardization, missing values, duplicate records, and date formatting.

## Tools and Functions Used
- Microsoft Excel
- IF and ISBLANK
- TRIM and CLEAN
- PROPER
- COUNTIF
- AVERAGE and MEDIAN
- TEXT and DATEVALUE
- SUBSTITUTE and CONCAT
- Conditional Formatting
- Remove Duplicates

## Workbook Sheets
- **Raw_Employee_Data:** Employee information, including names, departments, joining dates, emails, phone numbers, and salaries.
- **Sales_Transactions:** Sales records containing transaction IDs, employee IDs, products, quantities, prices, sales amounts, and dates.
- **Customer_Master:** Customer IDs, names, email addresses, phone numbers, cities, and countries.
- **Product_List:** Product IDs, product names, categories, prices, and stock availability.
- **Questions_Sheet:** Contains 30 data cleaning questions related to the datasets.

## Key Activities
- Identifying and removing duplicate records.
- Standardizing department names and product names.
- Removing extra spaces and non-printable characters.
- Handling missing email addresses, salaries, prices, and phone numbers.
- Standardizing date formats.
- Correcting inconsistent text and category values.
- Converting text-based numeric values into numbers.
- Validating email addresses.
- Identifying duplicate product IDs.
- Detecting potential salary outliers.
- Extracting months from sales dates.
- Handling missing sales amounts.

## Learning Outcomes
- Improved understanding of data cleaning techniques in Excel.
- Practiced handling missing values and duplicate records.
- Learned to standardize text and date formats.
- Improved skills in data validation and error identification.
- Gained experience preparing datasets for further analysis.
